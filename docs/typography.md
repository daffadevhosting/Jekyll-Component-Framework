# Typography

Utility and element styles for a consistent type scale.

## Scale

| Class | Use |
|-------|-----|
| `.t-display` | Hero / marketing display |
| `.t-h1` … `.t-h6` | Headings (also style native `h1`–`h6`) |
| `.t-body` | Body text |
| `.t-lead` | Intro / lead paragraph |
| `.t-small` | Secondary text |
| `.t-caption` | Meta / captions |
| `.t-code` | Inline code |

## Color helpers

`.t-muted` · `.t-subtle` · `.t-primary` · `.t-success` · `.t-warning` · `.t-danger`

## Alignment

`.t-center` · `.t-left` · `.t-right`

## Example

<p class="t-display">Display</p>
<h1 class="t-h1">Heading 1</h1>
<h2 class="t-h2">Heading 2</h2>
<p class="t-lead">Lead paragraph for introductions.</p>
<p class="t-body">Body text with comfortable line height for reading.</p>
<p class="t-small t-muted">Small muted supporting text.</p>
